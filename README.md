# Aerial Object Classification & Detection
This repository contains Jupyter Notebooks for detecting and classifying objects from aerial imagery. The project leverages deep learning techniques, including YOLOv8, to perform object detection tasks on aerial datasets.

# 📁 Project Structure
The repository consists of the following notebooks:

aerial object classification & detection.ipynb: The primary notebook containing the workflow for aerial object classification and detection.

yolov8_object_detection.ipynb: Implementation of object detection using the YOLOv8 model architecture.

Copy_of_Untitled0.ipynb: Additional workspace/draft notebook.

# 🚀 Getting Started
Since these are Jupyter Notebooks, you can run them locally or using cloud-based platforms like Google Colab (which was originally used to create them).

# Prerequisites
To run these notebooks locally, you will need Python installed along with Jupyter and standard machine learning libraries. Specifically for YOLOv8, you will need the ultralytics package:

Bash

pip install jupyterlab

pip install ultralytics

pip install opencv-python matplotlib
# Installation
# 1.Clone the repository:

Bash

git clone https://github.com/banul25/aerail_object_classification_detection.git
# 2.Navigate to the project directory:

Bash

cd aerail_object_classification_detection
# 3.Launch Jupyter Notebook / JupyterLab:

Bash
